SDF Frame Pipeline Overview

MathOPS SDF Engine — Blender 5.0 Fork — GPU Compute Pipeline
Pass Dispatch Workgroup Output What it does
1. Tile Cull (tilesX, tilesY, 1) (8, 8, 1) tile_prim_counts[]
tile_prim_lists[]		 Frustum-tests each SDF object's AABB against 8×8 screen tiles. Builds per-tile primitive lists so later passes skip irrelevant objects.
— SHADER_STORAGE barrier —
2. Cone March
(optional)		 (⌈tilesX/8⌉, ⌈tilesY/8⌉, 1) (8, 8, 1) tile_hit_pos[]
tile_far_hint[]		 Coarse cone trace per tile — wide aperture, few steps. Finds approximate hit distance so the fine trace can skip empty space.
— SHADER_STORAGE barrier —
3. Sphere Trace (W/8, H/8, 1) (8, 8, 1) gbuf_pos   (f32×4)
gbuf_color (f16×4)		 Per-pixel sphere tracing with over-relaxation. Evaluates SDF primitives, CSG ops, smooth blends, and modifiers. Reads tile lists + cone hints. Outputs G-buffer.
— IMAGE_ACCESS barrier —
4. Shade (W/8, H/8, 1) (8, 8, 1) out_color (f16×4)
out_depth (f32)		 Reads G-buffer, computes best-fit triangle normals from neighbor positions (same-object-ID preference to avoid CSG bleed). Applies studio lighting (4-light rig), matcap, or flat shading. Writes final color + depth.
— TEXTURE_FETCH barrier —
5. Blit drawArrays(3) N/A Framebuffer Full-screen triangle. Samples color + depth textures, composites into Blender's viewport with depth testing (SDF ↔ mesh occlusion).
6. FXAA
(optional)		 drawArrays(3) N/A Framebuffer Post-process anti-aliasing. Smooths per-pixel ray march jaggies via intermediate texture + alpha blit.
W, H = render resolution (viewport × resolution scale).   tilesX, tilesY = ⌈W/8⌉, ⌈H/8⌉.   All compute shaders use 8×8 workgroups (64 threads).   BVH (SAH AABB tree) built on CPU, uploaded as SSBO — sphere trace uses it for O(log N) spatial queries.   Adaptive resolution renders at lower res during navigation, refines when stationary.
